Core Features & Tools ​

📸 Terminal Screenshot Studio ​

Capture Carbon.sh-style aesthetic terminal snapshots with custom backgrounds, shadows, and branding:

  • Quick Dropdown: Click Screenshot in the top tab bar to instantly Copy to Clipboard or Save to Computer.
  • Screenshot Studio Modal: Open the full studio to customize:
    • Background Gradient: Toggle on/off or choose between Indigo, Slate, Cyber, Sunset, Emerald, Rose, Obsidian, and Transparent.
    • Canvas Padding: Adjust padding dynamically (0px tight crop, 16px, 36px, 56px).
    • Window Controls: Toggle macOS traffic light buttons (Red, Yellow, Green).
    • Native Save Dialog: Interactively browse and choose your target folder on your computer.

🔤 Dynamic System Font Management ​

TermBolt avoids hardcoded font lists and queries all fonts installed on your computer dynamically via the System Font Repository Pattern:

  • Windows: Queries the Windows Registry (HKLM & HKCU Fonts) and %WINDIR%\Fonts.
  • macOS: Reads /System/Library/Fonts, /Library/Fonts, and ~/Library/Fonts.
  • Linux: Scans via fontconfig (fc-list) and /usr/share/fonts.
  • Smart Grouping: Automatically categorizes fonts into Monospace Fonts (e.g. Cascadia Code, Fira Code, JetBrains Mono, Consolas, Nerd Fonts) and All Installed System Fonts.
  • Custom Font Mode: Easily toggle to manual text entry to specify any bespoke font name.

🔒 Encrypted Master Vault ​

  • Zero-Knowledge Encryption: Your server passwords and SSH private keys are never stored in plaintext. They are protected using PBKDF2 SHA-256 (100,000 iterations) and authenticated AES-256-GCM encryption.
  • Auto-Lock Security: Automatically locks credential access after inactivity.

☁️ End-to-End Encrypted Cloud Sync ​

  • Cryptographic Binary Snapshots: Export your entire server fleet, folders, snippets, and button bars into a .termbolt binary snapshot encrypted with AES-256-GCM.
  • Google Drive Integration: Connect your Google account with OAuth 2.0 PKCE loopback authentication.
  • Interactive Conflict Resolver: Compare local vs remote versions and resolve conflicts per item during snapshot restoration.

📂 Server-to-Server SFTP File & Directory Copying ​

TermBolt includes a comprehensive, cross-platform file management and server-to-server copying suite:

  • Zero Local Disk Buffering: Direct streaming between remote SSH/SFTP servers in memory chunks without downloading files to your local hard drive.
  • Dual Host Selectors: Both Left and Right panes feature a dropdown to choose any host (Local Machine or any configured remote SSH server).
  • Right-Click Context Menu: Right-click any file row or directory to quickly transfer, open, change permissions (chmod), change ownership (chown), rename, create new files/folders, copy full paths, or delete.
  • Sudo / Root Privilege Escalation: Execute file operations with elevated permissions using the SUDO toolbar toggle or automatic elevation prompt when encountering permission denied errors.
  • Permissions Inspector: Live POSIX permission strings (drwxr-xr-x, -rw-r--r--) and octal modes displayed in file tables.
  • Recursive Directory Transfers: Seamlessly copy entire directory trees with all subfolders and files.
  • One-Click Pane Swap ($\rightleftarrows$): Instantly swap Left and Right host panes and paths.
  • Directory Operations: Create new directories on remote or local filesystems, perform bulk deletions with confirmation dialogs, and filter files instantly.
  • Live Transfer Progress: Real-time progress bar and status notifications tracking transferred items and completion.
  • 100% Cross-Platform: Fully compatible across Windows, macOS, and Linux.

⚡ Synchronized Terminal Engine & Persistent Tab Lifecycle ​

  • Persistent Multi-Tab Sessions: Terminal processes and buffers remain continuously mounted in memory across tab switches with zero session interruptions or unexpected disconnects.
  • Configurable Idle Keep-Alive: Choose how long idle terminal sessions remain open (from 5 minutes, 15 minutes, 1 hour, up to Indefinite / Always Keep Alive).
  • SSH Keep-Alive Heartbeat: Periodic keepalive ping packets prevent router and firewall disconnections during idle periods.
  • Native ResizeObserver: Continuous synchronization between container viewport and the backend PTY/SSH shell prevents bottom clipping and cursor overdrawing.
  • 10,000-Line Scrollback: High-capacity buffer with instantaneous scrolling on keyboard activity.
  • In-Terminal Find (Ctrl+F): Floating search widget with case-matching and quick navigation.

🚀 Native Window Experience & Splash Screen ​

  • Native Taskbar Adherence: Full-screen maximization respects Windows work area bounds without obscuring the system taskbar.
  • Startup Splash Screen: Animated glowing logo and loading progress with customizable duration and opt-out preferences in Settings.

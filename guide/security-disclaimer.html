🔒 Responsible Use Policy ​

TermBolt is a remote access and terminal management client that handles server connection parameters, host keys, and credentials. Users are responsible for:

  1. Securing Local Master Passwords: Choose a strong master key for the Master Password Vault.
  2. Reviewing Connection Profiles: Verify SSH host fingerprints and network security before connecting to remote servers.
  3. Environment Tagging: Utilize TermBolt's built-in safety color badges (Production Red, Staging Amber, Dev Green) to prevent inadvertent destructive operations on critical production servers.

🛡️ Vulnerability Reporting ​

If you discover a security vulnerability in TermBolt, please report it privately using GitHub's "Report a vulnerability" button under the Releases Repository Security Tab rather than opening a public issue.

We acknowledge and triage security reports promptly to investigate and release fixes.

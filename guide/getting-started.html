Getting Started with TermBolt ​

Welcome to TermBolt, an ultra-fast, modern remote access client designed for system administrators, DevOps engineers, and developers managing fleets of remote servers and local workstations.

📥 Installation ​

🪟 Windows (Setup Wizard) ​

  1. Download TermBolt-Setup.exe from the Official Releases.
  2. Run the installer wizard. TermBolt will install seamlessly to C:\Program Files\TermBolt (or %LOCALAPPDATA%\Programs\TermBolt) with desktop and start menu shortcuts.
  3. Launch TermBolt from your desktop or start menu.

🍎 macOS (Apple Silicon & Intel) ​

  1. Download TermBolt-mac-arm64.dmg (Apple Silicon) or TermBolt-mac-x64.dmg (Intel).
  2. Open the .dmg file and drag TermBolt into your /Applications folder.
  3. Launch TermBolt from Launchpad or Spotlight.

🐧 Linux (AppImage & Debian Package) ​

  1. AppImage:
    bash
    chmod +x TermBolt-linux-x64.AppImage
./TermBolt-linux-x64.AppImage
  2. Debian / Ubuntu (.deb):
    bash
    sudo dpkg -i TermBolt-linux-amd64.deb
sudo apt-get install -f # resolve any missing dependencies

🤖 Android Companion Client ​

  1. Download TermBolt-android-arm64.apk to your Android device (Android 9.0+).
  2. Allow installation from unknown sources in settings if prompted.
  3. Open the APK to install the TermBolt mobile client.

🚀 Quick Tour ​

1. Connecting to a Server ​

  • Click the + button in the Host sidebar to add a new server profile.
  • Configure connection parameters: Protocol (SSH, Telnet, Local Shell, VNC), Address / IP, Port (default 22), and Credentials.
  • Double-click the host card to open a new tab session.

2. Fast Navigation via Command Launcher (Ctrl+K) ​

Press Ctrl + K from anywhere in the application to open the Fuzzy Quick-Connect Launcher. Type any keyword, server name, or IP to jump directly into the session.

3. In-Terminal Search (Ctrl+F) ​

Search your active scrollback buffer instantly by pressing Ctrl + F. Match navigation with Enter (next) and Shift+Enter (previous).

🔒 Master Vault Unlock ​

On first launch, you will be prompted to set an optional Master Password to lock your local credential vault.

  • All stored credentials (passwords, private keys, passphrases) are encrypted using AES-256-GCM with a PBKDF2 SHA-256 (100,000 rounds) derived key.
  • If locked, click the lock icon in the top titlebar or press Ctrl + , to enter your master key.
